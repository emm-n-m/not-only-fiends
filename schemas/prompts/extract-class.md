# Extract Class / Racial HD from D&D 3.5e Source Material

## Task

Extract class or racial HD data from the provided source text and output valid JSON matching the HDDriver schema. Output a JSON array (even for a single class).

## Output Format

- Root is a JSON array: `[{ ... }]`
- Use **camelCase** for all property names and enum values
- Omit null/empty optional fields (the engine ignores nulls)
- The `$type` discriminator field is **required** on all polymorphic objects (Permabuff and Prerequisite types)

## Schema

Use `schemas/hddriver.schema.json` (self-contained, paste it into your context alongside this prompt).

## Critical Rules

### ID Conventions
- Base classes: `"id": "class:snake_case_name"` (e.g., `class:fighter`, `class:sorcerer`)
- Prestige classes: `"id": "class:snake_case_name"` (e.g., `class:eldritch_knight`, `class:arcane_trickster`)
- Racial HD: `"id": "racial_hd:snake_case_name"` (e.g., `racial_hd:outsider`, `racial_hd:dragon`)

### Auto-Computed Permabuffs — DO NOT USE
These permabuff types are auto-generated by the engine from the driver's top-level fields. **NEVER** place them in `levelPermabuffs` or `perLevelPermabuffs`:
- `AddHitDie` — generated from `hitDie`
- `AddBAB` — generated from `babProgression`
- `AddSaves` — generated from `saveProgression`
- `GrantSkillPoints` — generated from `skillPointsPerLevel`
- `AddClassSkills` — generated from `classSkills`
- `UpdateSpellcasting` — generated from `spellcasting`

### What Goes in levelPermabuffs
Only user-facing class features:
- **GrantAbility** / **RevokeAbility** — for class features (Rage, Uncanny Dodge, Trap Sense, etc.)
- **GrantSLA** / **RevokeSLA** — for spell-like abilities granted at specific levels
- **GrantBonusFeat** — for automatic feats (e.g., Track for rangers)
- **GrantFeatSlot** — for bonus feat selection slots (e.g., fighter bonus feats at even levels)
- **ModifyAttribute** / **SetAttribute** — for permanent stat changes at specific levels
- **GrantMovement** — for a class feature that grants a movement mode; include `flyManeuverability` when granting flight
- **AdvanceSpellcasting** — for prestige classes that advance existing spellcasting

### Ability Scaling Pattern
When an ability improves (e.g., Rage 1/day → 2/day, Trap Sense +1 → +2):
1. **RevokeAbility** the old version (by its `abilityId`)
2. **GrantAbility** the new version (with a new `id`)

Each version gets a unique ID (e.g., `rage`, `rage_2`, `rage_3`, `greater_rage`).

### Prestige Classes
- Set `maxLevel` (typically 5 or 10)
- Add `prerequisites` (MinBAB, MinSkillRanks, HasFeat, CanCastSpellLevel, etc.)
- `MinSkillRanks.value` is authored in **whole ranks** (e.g., Archmage's "15 ranks Spellcraft" → `value: 15`). The engine stores ranks as half-ranks internally and doubles at comparison time; do NOT pre-double.
- `HasFeat` matches exact ID or any `{featId}_*` selection variant — for prereqs on selectable feats (e.g., Archmage's "Spell Focus in two schools"), use `HasFeatSelections { featId: "spell_focus", minCount: 2 }`; single-selection cases can use `HasFeat { featId: "spell_focus" }` since the prefix match finds any variant.
- If the class advances spellcasting: add `AdvanceSpellcasting` in `levelPermabuffs` at each level that grants "+1 level of existing spellcasting class"
- Level 1 of a prestige class typically does NOT advance spellcasting

### Spellcasting
- Only for classes with their own spell progression (wizard, cleric, sorcerer, bard, etc.)
- `spellsPerDay`: keys are class levels (1-20), values map spell level to slot count
- `spellsKnown`: **only** for spontaneous casters (sorcerer, bard). Omit for prepared casters.
- `castingStat`: `"int"` (wizard), `"wis"` (cleric, druid, ranger), `"cha"` (sorcerer, bard, paladin)

### Racial HD
- Set `"kind": "racialHD"` and `"id": "racial_hd:type_name"`
- Add `HasRace` prerequisite pointing to the race definition ID
- `levelPermabuffs` is usually empty (racial features go on the RaceDefinition instead)

### Skill IDs
Use `snake_case`: `knowledge_arcana`, `handle_animal`, `sense_motive`, `use_magic_device`, etc.
